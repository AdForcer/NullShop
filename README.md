# NullShop — E-Commerce RESTful API

Асинхронный REST API сервис для интернет-магазина, разработанный на базе **FastAPI** и **SQLAlchemy 2.0 (Async)** с хранилищем данных на **PostgreSQL**.

Проект включает ролевую модель доступа (RBAC), полнотекстовый поиск товаров через PostgreSQL `TSVector`, а также систему пользовательских отзывов с автоматическим пересчетом среднего рейтинга товаров.

## Особенности и возможности

- **Аутентификация и авторизация:**
  - Реализация OAuth2 (Password Flow) с использованием JWT-токенов (`access_token` и `refresh_token`).
  - Хеширование паролей при помощи алгоритма Argon2 (`pwdlib[argon2]`).
  - Защищенные маршруты с валидацией ролей через зависимости FastAPI.

- **Управление каталогом (Products):**
  - Пагинация выдачи (`page`, `page_size`), фильтрация по категориям, диапазону цен и наличию на складе.
  - Полнотекстовый поиск по наименованию и описанию через `TSVector` (PostgreSQL).
  - Контроль доступа: создание и редактирование товаров доступны только продавцам (`seller`).

- **Управление категориями (Categories):**
  - Иерархическое структурирование товаров.
  - Мягкое удаление категорий (`is_active = False`) с доступом только для администраторов (`admin`).

- **Система отзывов и рейтинга (Reviews):**
  - Возможность публикации оценок и отзывов авторизованными покупателями (`buyer`).
  - Автоматический пересчет и обновление общего рейтинга товара при добавлении новых отзывов.
  - Поддержка мягкого удаления отзывов.

## Ролевая модель (RBAC)

| Роль (`role`) | Описание прав доступа |
| :--- | :--- |
| `buyer` | Просмотр каталога, добавление отзывов к товарам, просмотр своего профиля. |
| `seller` | Создание, редактирование и удаление собственных товаров, просмотр каталога. |
| `admin` | Полное управление категориями товаров, администрирование системы. |

## Инструкция по установке и запуску

### 1. Клонирование репозитория

```bash
git clone https://github.com/Azonjou/NullShop.git
cd NullShop
```

### 2. Создание и активация виртуального окружения

```bash
# Создание окружения
python -m venv venv

# Активация на Linux / macOS:
source venv/bin/activate

# Активация на Windows:
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корневом каталоге проекта:

```env
SECRET_KEY=b4c09517c62a39dc2df795800dfd09d5450fb73b8bc8f35a11cd79835ab5fc00
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
DATABASE_URL=-
```

### 5. Выполнение миграций базы данных

```bash
alembic upgrade head
```

### 6. Запуск сервера разработки

```bash
uvicorn app.main:app --reload
```

API будет доступно по адресу: `http://127.0.0.1:8000`

## Обзор эндпоинтов API

Интерактивная документация формируется автоматически:

- **Swagger UI:** `http://127.0.0.1:8000/docs`
- **ReDoc:** `http://127.0.0.1:8000/redoc`

### Основные маршруты

#### Авторизация и пользователи (`/users`)
- `POST /users` — регистрация нового пользователя.
- `POST /users/token` — получение пары токенов (`access_token`, `refresh_token`).
- `POST /users/refresh-token` — обновление токена доступа.
- `GET /users/me` — получение данных текущего авторизованного пользователя.

#### Товары (`/products`)
- `GET /products` — постраничный список товаров с фильтрами по цене и категории.
- `GET /products/search` — полнотекстовый поиск по названию и описанию.
- `GET /products/{product_id}` — получение детальной информации о товаре.
- `POST /products` — добавление нового товара *(требуется роль `seller`)*.
- `PUT /products/{product_id}` — обновление товара *(только создатель-продавец)*.
- `DELETE /products/{product_id}` — мягкое удаление товара *(только создатель-продавец)*.

#### Категории (`/categories`)
- `GET /categories` — список всех доступных категорий.
- `POST /categories` — создание категории *(требуется роль `admin`)*.
- `PUT /categories/{category_id}` — обновление категории *(требуется роль `admin`)*.
- `DELETE /categories/{category_id}` — удаление категории *(требуется роль `admin`)*.

#### Отзывы (`/reviews`)
- `GET /reviews/products/{product_id}` — получение отзывов конкретного товара.
- `POST /reviews` — публикация отзыва и оценки *(требуется роль `buyer`)*.
- `DELETE /reviews/{review_id}` — удаление отзыва.
